# FAQ

The Operator's brain. Every question customers ask repeatedly, with the exact
answer in your voice. If the Operator gets something wrong, add a line here
instead of fixing the same thing twice — this file is the boundary: if an
answer isn't here, the Operator escalates instead of improvising.

## Format

```
### Q: <question as customers actually phrase it>
A: <the exact reply, in your voice>
```
